# THE LEARNING EDITION — Instructional Design Portfolio

A premium editorial / luxury-hotel-newspaper inspired portfolio built as static HTML/CSS/JS for GitHub Pages.

## Design direction

- Luxury editorial / broadsheet structure
- Warm paper palette with ink-black contrast
- Refined serif display typography + technical monospace metadata
- Asymmetric editorial grids
- Subtle paper grain
- Futuristic orbital graphic language
- Case files instead of generic portfolio cards
- Dedicated collaboration/contact correspondence section

The visual language takes inspiration from premium hotel publications and editorial design: restrained typography, generous whitespace, strong grids and high-value imagery rather than a conventional corporate portfolio.

## Setup

1. Replace `Your Name`, LinkedIn URL and email in `index.html`.
2. Create a Formspree form and replace `YOUR_FORMSPREE_ID`.
3. Replace case-study placeholders with your actual work.
4. Add images/PDFs/prototypes to the repository.
5. Enable GitHub Pages under repository Settings → Pages.
